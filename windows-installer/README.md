# TV Home Installer для Windows

[Русский](README.md) | [English](README.en.md)

Запустите `TV-Home-Installer.exe` на Windows 10 или 11. Установщик использует один `TV-Home-Apple-Style.apk` версии 3.6 для Android TV и Google TV на Android 8–14. Этот же APK встроен в EXE. Кнопка «APK для флешки» сохраняет его вместе с `TV-Home-USB-Instruction.txt` в выбранную папку. Кнопка «Инструкция» открывает памятку в приложении. [Файлы для скачивания](../README.ru.md#скачать-и-установить)

1. В настройках ТВ откройте «Об устройстве» и нажмите OK 7 раз на пункте «Сборка». Вернитесь в раздел «Для разработчиков» и включите сетевую или беспроводную отладку. Подключите ТВ и ПК к одной сети. [Пошаговая инструкция](TV-Home-USB-Instruction.txt)
2. Введите IPv4-адрес. Для обычного сетевого ADB используется порт 5555. Если в меню «Беспроводная отладка» показан другой порт, введите `IP:порт`. Для первого подключения по коду используйте кнопку «Сопряжение…» и введите адрес из окна сопряжения. После него укажите порт подключения из главного экрана беспроводной отладки.
3. Нажмите «Установить лаунчер». По умолчанию установщик проверит, что новый Home открылся, затем отключит найденный штатный Home и проверит выбор Android. Если найдено несколько вариантов, нажмите «Подключить» и выберите штатный Home в списке.
4. Кнопка «Включить старый» возвращает штатный главный экран. Когда он включён, эта же кнопка предлагает «Выключить старый».

Для установки с флешки скопируйте на неё единственный APK и откройте его на ТВ. После установки подключите телевизор в Windows-приложении и нажмите «Выключить старый». Android разрешает изменение состояния чужого системного пакета привилегированным инструментам, таким как авторизованный ADB. [Документация Android](https://developer.android.com/reference/android/Manifest.permission#CHANGE_COMPONENT_ENABLED_STATE)

ADB связывает компьютер с телевизором. ADB 37.0.1 уже встроен в EXE и автоматически распаковывается при первом подключении. Для работы достаточно локальной сети между ПК и ТВ. [Состав и лицензии встроенного ADB](vendor/README.md)

Определение Home использует данные Android и список системных пакетов, поэтому модель вводить не требуется. Возможность сетевого ADB и смены Home зависит от прошивки. Если система запрещает переключение или штатный Home совмещён с системными настройками, приложение сообщит об ограничении. [Сетевая отладка Android](https://developer.android.com/tools/adb#connect-to-a-device-over-wi-fi)

Для повторной сборки из клона репозитория запустите `windows-installer/Build.ps1` в PowerShell. Скрипт проверяет SHA-256 APK из `downloads/` или `export/`, компилирует EXE через локальный .NET Framework и сохраняет EXE и TXT в `export/`.
