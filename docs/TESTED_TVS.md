## Xiaomi Mini LED 55 2025

- Модель: MiTV-MOEU1; аппаратное имя lalaland.
- Система: Android 14 / API 34, заводской регион RU.
- Основные проверки выполнены в основной сборке 3.2; переключение RU/EN, сохранение языка при обновлении и новые снимки проверены в 3.3 и повторно в 3.4. На этом телевизоре использовалась внешняя тема; переносная сборка дополнительно содержит встроенный вариант темы и домик.

## KIVI 4K Android TV — переносная сборка 3.5

- Система сообщает модель KIVI 4K Android TV, устройство bangbae, Android 11 / API 30, сборку RTO8.260427.001. Отдельный коммерческий артикул панели не определялся.
- Установлен именно переносной APK 3.5-portable5 / code 17; данные сохранены. Android сообщает UI 1920×1080, density 320. Все 28 файлов обоев в APK имеют размер 3840×2160.

| Проверка | Реальный результат |
| --- | --- |
| Новый Home | Простое назначение прошивка игнорировала. После отдельно разрешённого обратимого отключения stock Home системный Home открывает наш лаунчер напрямую |
| Реальная перезагрузка | Новый Home появился самостоятельно; перемещённые плитки, выбранные язык/обои и 17 disabled-пакетов сохранились |
| ТВ и домик (3.5) | Обе плитки реально перемещены; в меню только dock и перемещение, без удаления. После испытания возвращена исходная раскладка |
| RU/EN | Английские Home и настройки показаны на ТВ, затем через интерфейс восстановлен русский |
| Обои | Открыты превью всех 7 тем, проверены 4 периода, Автоматически и Выкл./Вкл.; на Home показан Хэллоуин. Выбор пережил обновление и перезагрузку |
| Bluetooth/пульт | Открыт штатный раздел «Пульты и аксессуары», показан KIVI RC60; сопряжения не менялись |

| Плитка ТВ | Открыт штатный com.mediatek.wwtv.tvcenter с интерфейсом кабельного канала; Home вернул лаунчер. Качество видео/звука не оценивалось |
| Приложения | Проверен запуск YouTube, VK Видео и Кинопоиска и возврат Home; реальное потоковое воспроизведение не оценивалось. Happ сохранён, VPN не включался |

| Физический пульт KIVI | Пользователь подтвердил прямой Home без мелькания старого экрана и непрерывную громкость при удержании |
| Фоновые процессы KIVI | У 14 пакетов из списка очистки процессов не найдено. Процесс Anoki ACR с флагом SYSTEM PERSISTENT остался в памяти после disable-user и force-stop; полное прекращение его выполнения не подтверждено |
| Отдельная очистка | С согласия владельца отключены 15 пакетов, включая stock Home; ещё 2 были отключены заранее. Данные приложений не удалялись; VK Видео сохранён |
| Восстановление | Публичный Restore-Kivi.ps1 в режиме Home реально вернул штатный Home; затем возвращён новый. Режим All проверен только через WhatIf; защита от чужой модели проверена на Xiaomi |
| Заставка/службы | Backdrop, таймеры сна/экрана и исходный список специальных служб сохранены. Перехват клавиш и помощник системного меню на KIVI не включались |

Полный просмотр всех 28 фонов в полный экран, реальная работа VPN/AirPlay и точный переход к перезагрузке на Android 11 не проверялись. Удержание громкости и отсутствие мелькания Home подтверждены владельцем KIVI; выход Home из заставки на KIVI ещё не проверялся.

[Возврат штатного KIVI Home](RESTORE_KIVI.md).

## Что пока не проверено

- Другие модели Android TV / Google TV, кроме указанных Xiaomi и KIVI.
- Поведение всех системных переходов на Android 8–13 и других прошивках.
- Воспроизведение HDMI-видео, всех телеканалов и разных сторонних плееров.
- Практическая работа VPN и AirPlay с iPhone в рамках этого выпуска.

Нет подтверждённых испытаний на Samsung Tizen и LG webOS; Android APK для этих систем не предназначен.
