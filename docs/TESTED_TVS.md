## Xiaomi Mini LED 55 2025

- Модель: MiTV-MOEU1; аппаратное имя lalaland.
- Система: Android 14 / API 34, заводской регион RU.
- Основные проверки выполнены в основной сборке 3.2; переключение RU/EN, сохранение языка при обновлении и новые снимки проверены в 3.3 и повторно в 3.4. На этом телевизоре использовалась внешняя тема; переносная сборка дополнительно содержит встроенный вариант темы и домик.

| Проверка | Реальный результат |
| --- | --- |
| Язык RU/EN (3.3) | Настройки, Home, погода, список приложений и HDMI-диалоги показаны на английском; выбор сохранился после pm install-r; русский восстановлен через интерфейс |
| Состояние после обновления 3.3 | 21 отключённый пакет без изменений, default Home наш; enabled только SystemMenuService, таймеры заставки/сна сохранены |
| Фоны (3.4) | Открыты все 7 тем; четыре варианта времени суток, автоматический режим и Выкл./Вкл. проверены на ТВ. Тема/включение сохранились после обновления APK |
| Файлы 4К (3.4) | В APK проверены все 28 JPEG: каждый 3840×2160. Это увеличение согласованных иллюстраций. Системное меню этого Xiaomi остаётся 1920×1080 из-за лимита прошивки config_maxUiWidth=1920 |
| Языки нового меню (3.4) | Настройки фона и Home проверены на EN, затем восстановлен RU; выбран After the Bell, Вкл., Автоматически |
| Новый Home и домик | Открывают новый лаунчер; возврат из ТВ-источника проверен |

На этой прошивке стандартный Bluetooth action не обрабатывался; использован штатный раздел аксессуаров через SliceActivity. У меню «Система» потребовался отдельный ограниченный помощник. На другой прошивке поведение может отличаться.

## Что пока не проверено

- Переносной APK на втором телевизоре и других моделях Android TV / Google TV.
- Поведение всех системных переходов на Android 8–13 и других прошивках.
- Воспроизведение HDMI-видео, всех телеканалов и разных сторонних плееров.
- Практическая работа VPN и AirPlay с iPhone в рамках этого выпуска.

Нет подтверждённых испытаний на Samsung Tizen и LG webOS; Android APK для этих систем не предназначен.

## Автоматические проверки

Переносная сборка: 315 JVM-тестов, 0 ошибок lint (101 предупреждение), успешная сборка APK. Проверены подпись, целостность ZIP, встроенная тема и лицензии. Эти проверки не заменяют установку на конкретную модель.
