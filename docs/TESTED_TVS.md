# Проверенные телевизоры

Дата фиксации: 30 октября 2026 года.

## Xiaomi Mini LED 55 2025

- Модель: MiTV-MOEU1; аппаратное имя lalaland.
- Система: Android 14 / API 34, заводской регион RU.
- Проверки выполнены в основной сборке 3.2. На этом телевизоре использовалась внешняя тема; переносная сборка дополнительно содержит встроенный вариант темы и домик.

| Проверка | Реальный результат |
| --- | --- |
| Новый Home и домик | Открывают новый лаунчер; возврат из ТВ-источника проверен |
| Мелькание старого Home | После обратимого отключения родного лаунчера пользователь подтвердил отсутствие мелькания |
| Удержание громкости и Home из заставки | Пользователь подтвердил в предыдущей основной сборке 3.1; перехват клавиш остаётся выключенным |
| Запуск после перезагрузки | Подтверждён на основной 3.1; после обновления 3.2 реальная перезагрузка не выполнялась |
| Bluetooth и пульт | Открыт штатный раздел «Пульты и аксессуары», отображался подключённый Xiaomi RC |
| Плитка ТВ | Открывает native LiveTV; один Home возвращает лаунчер. Реальная картинка каналов не оценивалась |
| Источники | Показаны HDMI 1/2/3 без предзаданного имени Apple TV |
| Названия HDMI | Проверены сохранение имени, чтение после пересоздания экрана и удаление; тестовое имя удалено |
| Погода | Город определился автоматически; реальные текущие данные wttr.in отображались и обновлялись |
| Длинное название города | После исправления буква с нижним выносом не обрезается; положение основных плиток сохранено |
| Кнопка перезагрузки | Открыт штатный раздел «Система», выделен «Перезагрузить»; подтверждение не нажималось |
| Заставка и сон | Системные параметры сохранены; тайм-аут экрана 300000 мс, sleep_timeout=-1 |

На этой прошивке стандартный Bluetooth action не обрабатывался; использован штатный раздел аксессуаров через SliceActivity. У меню «Система» потребовался отдельный ограниченный помощник. На другой прошивке поведение может отличаться.

## Что пока не проверено

- Переносной APK на втором телевизоре и других моделях Android TV / Google TV.
- Поведение всех системных переходов на Android 8–13 и других прошивках.
- Воспроизведение HDMI-видео, всех телеканалов и разных сторонних плееров.
- Практическая работа VPN и AirPlay с iPhone в рамках этого выпуска.

Нет подтверждённых испытаний на Samsung Tizen и LG webOS; Android APK для этих систем не предназначен.

## Автоматические проверки

Переносная сборка: 307 JVM-тестов, 0 ошибок lint (99 предупреждений), успешная сборка APK. Проверены подпись, целостность ZIP, встроенная тема и лицензии. Эти проверки не заменяют установку на конкретную модель.
