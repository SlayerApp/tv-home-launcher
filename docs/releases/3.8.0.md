## English

- **Settings → Launcher update → Check for updates** checks the stable GitHub release while the TV is online. On the first install of an update, Android may ask you to allow installation from TV Home Launcher. The system installer asks you to confirm the update.
- The launcher verifies the APK checksum, Android package, version and signing certificate before giving it to the installer.
- Install this signed portable APK (`3.8.0-portable9`, code 23) over the existing launcher once to get this menu. Future updates can be initiated from the TV.

## Русский

- **Настройки → Обновление лаунчера → Проверить обновления** проверяет стабильный выпуск на GitHub. При первой установке Android может попросить разрешить установку из TV Home Launcher. Обновление подтверждается в системном установщике.
- Перед установкой лаунчер сверяет SHA-256, имя пакета, версию и подпись APK.
- Один раз установите подписанный APK `3.8.0-portable9` (код 23) поверх предыдущей версии. После этого обновление можно запускать с ТВ.
