# Background production

The working version 3.4 includes 28 JPEG wallpapers at 3840×2160. [Exact generation briefs](background-production-prompts.json) produced seven clean 2×2 source atlases. The approved scenes were then exported as separate 4K images by high-quality scaling and JPEG encoding. This export preserves the illustration and does not invent additional detail.

The earlier UI mockups are design studies. See [the implemented backgrounds](BACKGROUNDS.en.md) for controls and actual device checks.
